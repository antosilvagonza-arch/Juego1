# Laboratorio Inestable

Roguelike para Android (Kotlin + Jetpack Compose, sin librerías externas).

- Arrastra el dedo para mover al científico; dispara solo.
- Defiende el reactor. Cuando la inestabilidad llega al 100% el laboratorio explota.
- Al explotar ganas Eureka y compras mejoras permanentes.

## Compilar
- Android Studio (Koala o más reciente): File > Open, elige esta carpeta, espera el Sync y pulsa Run.
- GitHub: sube la carpeta; la pestaña Actions compila el APK (artefacto "LaboratorioInestable-debug").
